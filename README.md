# VEDA Technology – Day 27: Salesperson Performance Analysis

## Project Overview

This project analyzes salesperson performance using sales, profit, order volume, quantity, and average order value. A professional Excel dashboard was created to compare salesperson performance and generate actionable business recommendations.

## Objectives

- Compare salesperson sales performance
- Analyze profit contribution
- Rank salespersons based on sales
- Compare order volumes
- Calculate Average Order Value (AOV)
- Identify top-performing salespersons
- Generate actionable business recommendations

## Tools Used

- Microsoft Excel
- Excel Formulas
- Data Analysis
- Data Visualization
- Conditional Formatting

## Dataset

The dataset contains:

- Order ID
- Order Date
- Salesperson
- Region
- Category
- Sales
- Profit
- Quantity

## Key KPIs

- Total Sales: ₹544,300
- Total Profit: ₹95,810
- Total Orders: 40
- Average Order Value: ₹13,607.50

## Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Order Value KPI
- Salesperson Sales Ranking
- Profit by Salesperson
- Sales Contribution by Salesperson
- Key Insights & Recommendations

## Key Insights

- Priya is the top-performing salesperson based on sales and profit contribution.
- Neha demonstrates strong overall sales performance.
- Rahul and Aman have opportunities for performance improvement.
- Sales and profit should both be considered when evaluating salesperson performance.
- High-value and profitable orders should be prioritized.

## Recommendations

1. Recognize and reward high-performing salespersons.
2. Provide targeted coaching for lower-performing salespersons.
3. Focus on profitable and high-value orders.
4. Monitor salesperson performance using multiple KPIs.
5. Use both sales and profit for balanced performance evaluation.

## Project Outcome

The project provides a professional Excel-based performance dashboard that supports salesperson comparison, performance ranking, KPI tracking, and data-driven decision making.
